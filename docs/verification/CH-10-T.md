Radix handles complex keyboard/focus behavior; React 19 ref props and useId keep typed composition/field association. Separate files, no domain orchestration, network, environment reads or storage. Presentation-only files remain server-safe; interactive leaves carry client boundaries. React skill review checked hooks, stable IDs, no derived-state effects, no fetching, small boundaries and no unnecessary chart/motion libraries.
- Test-only Vite/React compositions show shared primitives with retail imagery hierarchy and compact admin rows/toolbars. No production demo routes, product pages, KPI dashboards, business DTOs or requests. Light theme only. Long table content scrolls inside a named keyboard-focusable region, never via page overflow hiding.
