**APPROVED: Docker Desktop, WSL 2 and local Docker Compose are not mandatory development prerequisites.** Preserve PostgreSQL/Prisma, Redis/BullMQ, backend authority, real integration tests and reproducibility. Runner teardown removes service containers; any hosted ephemeral alternative needs an always-run owned-resource cleanup and expiry backstop. No production secrets, deployment permissions, privileged PR triggers or network fallback. Preserve commercehub-quality, immutable action review and security/audit policy; adding services/tests requires separate authorization and CI-policy-test review.

Teardown must stop only task-owned processes, revoke temporary credentials and delete only positively identified approved disposable data. Never use broad shared Redis flush or reset an existing Supabase database. A queue prefix alone is not infrastructure isolation.
