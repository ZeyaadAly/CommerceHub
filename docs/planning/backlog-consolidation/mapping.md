## Proposal changes from the owner starting map

Only five original-story owner moves are proposed: 031 → CH-12 (customer order API + UI); 032 → CH-13 (fulfillment API + UI); 041 → CH-04 (catalog admin vertical slice); 042 → CH-05 (inventory vertical slice); 044 → CH-03 (staff/RBAC vertical slice). All other supplied associations are unchanged. No phase changes. CH-09 now owns only 030/033, avoiding order APIs hidden inside jobs. CH-13 still owns shell/overview and fulfillment; CH-11/12 own real shopper journeys. Technical foundations CH-01/02/10 remain explicit enabling deliveries rather than artificial business journeys.

The 21 stories are delivery parents, not 21 giant PRs. A feature may consume an accepted contract from a different parent; each slice must prove its own API/schema/UI path. Acceptance or merge of one slice is not parent DONE. All historical source prose is retained; new gap ownership is proposed in coverage, not retroactively added to historical original acceptance.
